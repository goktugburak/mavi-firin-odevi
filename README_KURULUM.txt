MAVİ FIRIN - 10 HAFTALIK SEO DERSİ ÖRNEK WEB SİTESİ

1) index.html dosyasını çift tıklayıp tarayıcıda açın.
2) VS Code ile HTML ve CSS dosyalarını düzenleyin.
3) Yayın için GitHub Pages veya benzeri HTTPS barındırma kullanın.
4) Search Console doğrulama ve GA4 için yayınlanmış gerçek URL gereklidir.
5) sitemap-ORNEK.xml içindeki ORNEK-ADRES alanını yayın alan adınızla değiştirip sitemap.xml adıyla yayınlayın.
6) GA4'ün sağladığı GERÇEK Google etiketini her sayfanın <head> içine yerleştirin.
7) Bütün işletme bilgileri kurgusaldır; iletişim formu veri göndermez.
8) Gerçek veri toplamak için gizlilik ve çerez/onay yükümlülüklerini ayrıca değerlendirin.


HAFTA 1-3 TESLIM KONTROLU
- SEO: Her HTML sayfasinda anlamli title ve meta description bulunur.
- HTML/CSS: index.html ana sayfadir; style.css tum sayfalarda kullanilir.
- Baglantilar: index.html, urunler.html, hakkimizda.html ve iletisim.html baglantilarini kontrol edin.
- Mobil: Dar ekran icin viewport ve CSS media query kullanilir.
- GitHub Pages: Public mavi-firin deposu acin, bu klasorun ICERIGINI (site klasorunun kendisini degil) yukleyin.
- index.html depo kok dizininde bulunmali; Settings > Pages > Deploy from a branch > main > /(root) secin.
- Yayina alma ve telefon testi, GitHub hesabi gerektirdigi icin yerel dosyalardan otomatik yapilamaz.
- Yayindan sonra sitemap-ORNEK.xml dosyasindaki ORNEK-ADRES alanini gercek GitHub Pages adresiyle degistirip sitemap.xml adiyla yayinlayin.
